# Лаба 10: запросы для Консоли запросов

Консоль запросов (ConsSel Managed 8.3) это внешняя обработка, выданная на курсе. Открывается в режиме «1С:Предприятие» (толстый клиент): Файл → Открыть → файл обработки.
Дальше для каждого запроса: правой кнопкой в поле текста → «Открыть Конструктор запроса» (по желанию, чтобы показать, что можешь собрать запрос мышью), либо просто вставить текст ниже и нажать «Выполнить».

Данные для соединений (пункт 6): в справочнике Клиенты два клиента без района (Беляев Андрей, Григорьев Павел), в справочнике Районы три района без клиентов (Новый город, Центральный, Северный). Если их нет в базе, их создаёт обработка «ЗаполнениеДанных».

## Запрос 2 (Пункт 2): Сотрудники с должностями и датой приёма

```
ВЫБРАТЬ
	Сотрудники.Наименование КАК ФИО,
	Сотрудники.Должность КАК Должность,
	Сотрудники.ДатаПриема КАК ДатаПриема
ИЗ
	Справочник.Сотрудники КАК Сотрудники

УПОРЯДОЧИТЬ ПО
	ФИО
```

## Запрос 5 (Пункт 5): Услуги из всех документов ОказаниеУслуги без повторов (параметр ВидНоменклатуры = Услуга)

```
ВЫБРАТЬ РАЗЛИЧНЫЕ
	ОказаниеУслугиПереченьНоменклатуры.Номенклатура КАК Услуга
ИЗ
	Документ.ОказаниеУслуги.ПереченьНоменклатуры КАК ОказаниеУслугиПереченьНоменклатуры
ГДЕ
	ОказаниеУслугиПереченьНоменклатуры.Номенклатура.ВидНоменклатуры = &ВидНоменклатуры
```

Параметр `ВидНоменклатуры` на закладке «Параметры запроса»: значение «Услуга (перечисление ВидыНоменклатуры)».

```
ВЫБРАТЬ
	КОЛИЧЕСТВО(*) КАК КоличествоДокументов,
	КОЛИЧЕСТВО(РАЗЛИЧНЫЕ ОказаниеУслуги.Клиент) КАК КоличествоКлиентов
ИЗ
	Документ.ОказаниеУслуги КАК ОказаниеУслуги
```

## Что рассказать на защите
- Левое соединение: все клиенты, у кого нет района, получают NULL в поле Район.
- Правое соединение: все районы, у районов без клиентов в поле Клиент будет NULL; клиенты без района не попадают в результат.
- Полное соединение: объединение результатов левого и правого (клиенты без района и районы без клиентов в одном списке).
- Внутреннее соединение: только клиенты с районом и районы, у которых есть клиенты.
- В условии `Цена > 4000` число пишется как есть (в конструкторе нужна галочка «Произвольное»), иначе `4000` будет принято за параметр.
- `РАЗЛИЧНЫЕ` убирает повторы, `ПЕРВЫЕ N` берёт первые N строк с учётом упорядочивания, `ЭтоГруппа` отсекает группы иерархического справочника.
